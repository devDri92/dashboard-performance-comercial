# 📊 Dashboard de Performance Comercial

## 📌 Sobre o Projeto
Este projeto consiste no desenvolvimento de um dashboard interativo voltado para análise de desempenho comercial.

O objetivo foi transformar dados brutos em informações estratégicas, permitindo uma visão clara sobre receita, volume de vendas e comportamento ao longo do tempo.

## 🎯 Principais Indicadores
- Receita Total
- Quantidade Vendida
- Ticket Médio
- Receita ao longo do tempo
- Receita por Produto
- Receita por Região

## 🛠️ Etapas do Projeto

### 🔹 Tratamento de Dados
- Limpeza de dados inconsistentes
- Remoção de duplicidades
- Organização da base para análise

### 🔹 Modelagem de Dados
- Criação de tabela auxiliar de metas
- Relacionamento entre tabelas para análise integrada

### 🔹 Análise de Dados
- Construção de métricas de desempenho
- Análise de variação de receita ao longo do tempo
- Comparação entre produtos e regiões

### 🔹 Visualização
- Desenvolvimento de dashboard interativo
- Uso de filtros por período e região
- Criação de gráficos para facilitar a interpretação dos dados

## 📊 Ferramentas Utilizadas
- Power BI
- Excel
- Conceitos de Estatística e Probabilidade

## 📈 Resultados
O dashboard permite identificar:
- Tendências de crescimento ou queda na receita
- Produtos com maior impacto financeiro
- Diferenças de desempenho entre regiões
- Comportamento de vendas ao longo do tempo
